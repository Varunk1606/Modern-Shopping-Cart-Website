# Modern Shopping Cart Website

A **modern and responsive shopping cart web application** built using **HTML, CSS, JavaScript**, and a basic **Node.js backend**.  
This project is ideal for beginners and students to understand frontend fundamentals, DOM manipulation, and simple server setup.

---

## 🛍️ Features

- Product listing interface  
- Add items to cart  
- Remove items from cart  
- Automatic total price calculation  
- Responsive design (mobile & desktop)  
- Simple and clean UI  

---

## 🧰 Tech Stack

### Frontend
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
